# DevSecOps Platform – Final Report

## 1. Introduction
This project demonstrates a DevSecOps platform integrating CI/CD automation,
containerization, and security monitoring.

## 2. Architecture
Single-server architecture hosting application, CI/CD, and SIEM components.

## 3. DevOps Implementation
- GitHub repository management
- Docker containerization
- CI/CD via GitHub Actions
- SSH-based deployment

## 4. Security Implementation
- UFW firewall
- Fail2ban intrusion prevention
- Wazuh SIEM monitoring
- Elastic Stack log analysis

## 5. Attack Simulation
Controlled attacks validated detection capabilities.

## 6. Conclusion
This POC proves that a complete DevSecOps pipeline can be built using open-source tools.
